DryerOperatingStateEnum (DataType)

IsAbstract: False

- Fields

Identifier

Name

DataType

Description

Other

The dryer is in a state not specified by this enumeration.

Stopped

The dryer is stopped. This state is applicable to all adsorption dryers.

Running

The dryer is running. This state is applicable to all dryers.

RefrigerantCompressorStopped

The compressor of the refrigerant circuit is standing still, and the refrigerant dryer is operating using the stored cold. This state is applicable to refrigerant dryers.

RefrigerantCompressorRunning

The compressor of the refrigerant circuit is running and compressing refrigerant, creating cold. This state is applicable to refrigerant dryers.

PurgeValveClosed

Purge valve is closed, and no purge air is consumed, no purge of the humidity from membranes dryer. This state is applicable to membrane dryers.

PurgeValveOpen

Purge air can flow to purge the humidity out of the membrane dryer. This state is applicable to membrane dryers.

ParallelModeOfBothVessels

Both vessels of the adsorption dryer are used in parallel for adsorption. This state is applicable to all adsorption dryers.

Depressurizing

One vessel of the adsorption dryer is depressurized for regeneration. This state is applicable to heatless and heated adsorption dryers, not HOC.

Desorbing

One vessel of the adsorption dryer is in desorption phase, using purge or ambient air, heated or not heated. This state is applicable to all adsorption dryers.

Cooling

One vessel of the adsorption dryer is being cooled after being heated in the previous desorption phase. This state is applicable to heated adsorption dryers and HOC.

Pressurizing

The depressurized vessel is pressurized again. This state is applicable to heatless and heated adsorption dryers, not HOC.

RegeneratedVesselInStand-by

The regenerated vessel is in standby and ready for adsorption phase. This state is applicable to all adsorption dryers.
